# DSA Practice in C++

Welcome to your C++ Data Structures & Algorithms practice repository! The folders are organized in order of study to guide your practice systematically.

## 📁 Topic Directory Structure

1. **`01_CPP_Basics/`**: Syntax, Variables, Conditionals, Loops (`for`, `while`, `do-while`), Functions, Basic I/O.
2. **`02_Time_Space_Complexity/`**: Big-O notation, Time & Space Complexity analysis.
3. **`03_Arrays_and_Vectors/`**: 1D/2D Arrays, `std::vector`, Kadane's Algorithm, Two Pointers, Sliding Window.
4. **`04_Strings/`**: String manipulation, Character arrays, `std::string`, Substrings, Palindromes.
5. **`05_Searching_and_Sorting/`**: Binary Search, Linear Search, Bubble, Selection, Insertion, Merge, Quick, & Counting Sort.
6. **`06_Pointers_and_Memory/`**: Pointers, References, Dynamic Memory Allocation (`new`/`delete`), Memory Leaks.
7. **`07_Recursion_and_Backtracking/`**: Basics of Recursion, Subsets, Permutations, N-Queens, Sudoku Solver.
8. **`08_Bit_Manipulation/`**: Bitwise Operators (`&`, `|`, `^`, `~`, `<<`, `>>`), Bit Masks, Power Set.
9. **`09_Linked_List/`**: Singly Linked List, Doubly Linked List, Circular Linked List, Fast & Slow Pointers.
10. **`10_Stack_and_Queue/`**: Stack (`LIFO`), Queue (`FIFO`), Deque, Monotonic Stack/Queue, Infix/Postfix.
11. **`11_Trees_and_BST/`**: Binary Tree Traversals (BFS, DFS), Binary Search Tree (BST), AVL Trees.
12. **`12_Heap_and_Priority_Queue/`**: Min-Heap, Max-Heap, `std::priority_queue`, Heap Sort, Top-K elements.
13. **`13_Hashing_and_Maps/`**: Hash Tables, `std::unordered_map`, `std::unordered_set`, Frequency Counters.
14. **`14_Greedy_Algorithms/`**: Activity Selection, Fractional Knapsack, Huffman Coding.
15. **`15_Dynamic_Programming/`**: Memoization, Tabulation, 1D/2D DP, Knapsack, LCS, LIS.
16. **`16_Graphs/`**: Graph Representations (Adjacency Matrix/List), BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall.
17. **`17_Trie/`**: Prefix Tree, Word Search, Autocomplete logic.
18. **`18_Disjoint_Set_Union/`**: DSU / Union-Find with Path Compression & Union by Rank, Kruskal's Algorithm.
19. **`19_Advanced_Data_Structures/`**: Segment Trees, Fenwick Tree (Binary Indexed Tree).
20. **`20_Math_and_Number_Theory/`**: GCD/LCM (Euclidean Algorithm), Sieve of Eratosthenes, Modular Arithmetic.

Happy Coding! 🚀
